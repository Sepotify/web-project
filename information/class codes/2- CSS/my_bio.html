About Me

I am an Associate Professor specializing in Web Programming, Full-Stack Development, and Progressive Web Applications. My work bridges academic research and real-world software engineering.

"The web is not just a technology — it is the most powerful platform for human communication ever built."

I received my Ph.D. in Computer Science from MIT, with a dissertation on Scalable Architectures for Real-Time Web Applications. Before joining academia, I worked as a senior engineer at several tech companies, building large-scale distributed web systems.

Research Interests

  • Progressive Web Apps (PWA) & Service Workers
  • WebAssembly and browser-native performance
  • RESTful & GraphQL API design
  • Web security: XSS, CSRF, OAuth 2.0
  • Accessibility and inclusive web design
  • Real-time systems with WebSockets

Ongoing Projects

  1. EduWeb – An adaptive LMS built entirely on web standards
  2. SecureForm – A library for client-side form validation & sanitization
  3. WebPerf Monitor – Real-time browser performance analytics dashboard
